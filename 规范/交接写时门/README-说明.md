现役

这个目录是工具本身：脚本、给 AI 的操作手册（skill/）、回归测试（tests/）。README.md 是完整的技术说明（组成、命令、各项检查、每日学习、看门狗、安全边界、改它的规矩）。

README.md 里有一些链接指向使用者自己 docs 树里的文件（如 `工作传递/README.md`、`项目情况/`），本仓不带这些文件，链接打不开是正常的。文中的"本机"指唯一跑每日学习与弹窗的那台 Windows 电脑，"服务器"指只装写后检查的 Linux 机器；报告来源目录名、定时任务名照原样保留，按你自己的环境改 `handoff_common.py` 里的 `SOURCES` 与配置即可。
